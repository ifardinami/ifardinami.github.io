Foundation · start here

First the class, then the objects, then the wires

Everything starts with one idea in this exact order: define the class (the blueprint), build objects from it, then write the lines that connect those objects. Step through it on the right.

Class vs. object. A class is a blueprint — it describes the shape of a node but is not itself a usable node. Each time you write new Node(...) you stamp out one real object in memory that follows that blueprint. The class is written once; objects are made many times.
Connecting is just assignment. Two objects become a chain the moment you set one object's next field to point at another: n1.next = n2. No special command — wiring a linked list is only a series of these assignments.

Intro Linked List · Design the class

The six core list operations

A LinkedList wraps a single head reference and offers operations on top of it. Pick a method to see its pseudo-code and watch a temp pointer do the walking.

The walking pattern. Almost every method uses a borrowed pointer (often called temp) so the real head never gets lost. Loop while temp != null to visit every node; loop while temp.next != null to stop on the last node; loop while temp.next.next != null to stop on the second-to-last.
Lab Task 1

Assemble the Conga Line

You are the choreographer. Walk the line once and check that every dancer's age is not greater than the dancer in front. The moment one pair breaks the order, return false. Survive to the end and return true.

Sample input (ages)Expected
10 → 15 → 34 → 41 → 56 → 72true
10 → 15 → 44 → 41 → 56 → 72false
Single-pass, no extra structure. You never build a second list — you only compare each node with its neighbour. The constraint "you cannot use any other data structure" is satisfied because you walk the existing list once with one pointer.
Lab Task 2

The Word Decoder

Measure the list, compute step = 13 % length, then keep the letters whose position is a non-zero multiple of step. Because the message is stored backwards, push each kept letter to the front of a dummy-headed list — that reverses it for free.

Encodedlength & stepkept positionsdecoded
B M D T N O A P S C10, 13%10=33,6,9 → T,A,Cnull → C → A → T
Z O T N X5, 13%5=33 → Nnull → N
What is a dummy head? A node whose elem is null, sitting in front of the real data. It gives you a fixed handle to attach new nodes to, so "insert at the front" is always just newNode.next = dummy.next; dummy.next = newNode; — and that front-insertion is what flips the word into the right order.
